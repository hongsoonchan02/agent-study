# agent-study

AI 에이전트를 **쓰는 사람이자 만드는 사람**이 되기 위한 학습 레포입니다.
코딩 에이전트를 하네스·스킬스·SDD로 통제해서 쓰고, 같은 구조를 Python으로 프레임워크 없이 직접 만들어 봅니다.

## 운영 방식
- **A. 사용 트랙**: Claude Code 등 코딩 에이전트를 매일 실제 작업에 사용 (CLAUDE.md, Skills, hooks, 서브에이전트, MCP, SDD)
- **B. 구현 트랙**: Python으로 에이전트 루프 → 하네스 → eval·관측을 직접 구현
- **실패 노트**: 에이전트가 틀릴 때마다 [failure-notes.md](failure-notes.md)에 기록하고, 하네스(환경)로 막는 방법을 찾는다
- **Python**: 만들면서 모르는 문법만 그때그때 공부하고 [python-notes.md](python-notes.md)에 기록
